# 视频交付核对清单（每次必查）

开始剪辑时读本清单，在项目中建立 `交付核对清单.md`，记录本次范围、源文件、版本、检查日期和最终文件。各阶段完成时填写，交付前逐项收口。每项使用「通过 / 未通过 / 不适用」，附实际文件、时间点、截图或检测结果；不适用须写原因。不能用“导出成功”代替验收，适用项目未通过时不得宣称完整交付。

局部修改只重做受影响项目和边界回归，保留未改部分的有效证据。只改封面不重渲视频；只做诊断不要求成片。详细技术和模式要求见 [quality-checklist.md](quality-checklist.md)，本清单是执行入口，不另设一套标准。

| 阶段 | 必核对事项 | 结果与证据（项目中填写） |
| --- | --- | --- |
| 开始 | 本次剪辑模式、交付画幅、配乐选择、封面要求及用户例外已记录；不沿用上一条视频的配乐决定 | |
| 原片 | 原片身份、旋转、实际画幅、帧率、色彩、音轨和清晰度基线已检查，源文件保留 | |
| 清剪 | 失败重录、重复、口癖与无意义停顿已处理，无吞字；姓名、日期、数字准确；原片含自我介绍时完整保留，Will 的两个“说白了”不误删 | |
| 时间线冻结 | 清剪本地文件可完整解码；按权威剪辑顺序核对源区间、重复帧出现次数、实际视频帧数；不能只比较文件时长 | |
| 同步 | 重叠/复用/重排切点前后及尾段与原片逐帧映射核对，嘴型同步；音频母带相关性检查不能替代画面同步检查 | |
| 信息来源 | 官网截图、原始链接、抓取日期和素材出处已保存；当前状态、历史功能、未来计划、讲者分析分清，标题及图卡没有夸大保证 | |
| 首提图片 | 产品/人物别名合并，按最终保留口播的首次提及出现一次；实际图片已获确认；本人不叠图；成片仅显示图片，不另加名称或序号 | |
| 素材 | 看过选用片段的开头/中间/结尾，动作符合所讲含义；不合适就保留真人/图解并记原因，不凑素材数量；来源授权齐全 | |
| 素材画面 | 素材段无真人底层、抠像或圆窗，含留黑及入出边界；素材原声默认静音，无自动“示意”角标 | |
| 画面 | 对实际同时出现的标题、首提图、信息卡、手势、圆窗、字幕检查整段遮挡；保护完整头部、人脸与字幕，手机尺寸可读 | |
| 动效 | 逐句出现，前项固定保留、后项到口播点才揭示；稀疏信息侧卡、复杂解释画布、真人回归符合选定模式 | |
| 字幕 | 文字和时间来自最终口播，无静音幻觉、重叠或遗漏；粗白字、中性阴影、数据字色强调等遵循所选模式；无残留旧版字幕 | |
| 声音 | 只有一份对白；配乐符合本条选择，有音乐时低音量、不抢人声；提示音语义对齐，淡入淡出自然，无削波或失真 | |
| 画质 | 成片使用原片级素材，非低清预览放大；原片→清剪→成片对齐检查脸、头发、眼镜和肤色，实际像素及色彩标签正确 | |
| 导出 | 最终文件实际分辨率、帧率、视频帧数、时长、色彩、音轨已核对；全文件解码无错误；首/中/尾播放及关键边界检查完成 | |
| 工程 | 框架运行/布局检查通过；剩余提示有具体解释和实际画面证据；替换渲染路径时保留同一时间线并记录差异及验证 | |
| 封面 | 按本条要求保留并虚化原背景或重新设计；真人参考自然、完整头部无遮挡，标志准确，标题和关系有依据，透明科技元素服务主题 | |
| 封面版本 | 默认3:4及4:3分别排版，实际像素比例正确；逐张全尺寸和手机缩图核对，实拍参考帧/时间点/提示词保留 | |
| 交付包 | 成片、封面、字幕、EDL、可编辑工程、清剪交接、素材来源与必要署名、音效/配乐记录、本清单及验证证据可找到 | |

最终复核重点抽帧：第一帧与标题稳定态、自我介绍、首提图、最密集解释、素材入/中/出、真人回归、逐条列表各揭示前后、最后一帧。检查对象必须是实际最终文件；预览和参考渲染不能替代。
